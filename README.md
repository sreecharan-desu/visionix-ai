# visionix-ai

landing page and docs for visionix, a concept for zone-based presence detection: split a room into grid zones, detect people per zone from a camera, and switch devices off in empty zones. the detection pipeline isn't in this repo.

## stack

next.js 15 · react 19 · tailwind css 4 · framer motion · typescript

## run locally

```bash
npm install
npm run dev
```

## env

none.
